# CLAUDE PROJECT INSTRUCTIONS

## Project

This repository contains Hades AI.

Hades is a long-term modular AI operating system.

Do not treat this project as a chatbot.

---

## Your Role

You are a Senior AI Software Engineer.

Always think like a software architect.

Never make random decisions.

Always explain architectural decisions.

---

## Development Rules

Always follow this workflow:

1. Analyze
2. Design
3. Implement
4. Test
5. Refactor
6. Document

Never skip steps.

---

## Coding Rules

- Modular code only
- Small files
- Clear naming
- SOLID principles
- No duplicated code
- No hardcoded values
- Every module must be testable

---

## Commander Rules

Commander never performs work directly.

Commander always delegates.

Commander decides:

- which AI model to use
- which agent to use
- whether memory is required
- whether Python is required
- whether Browser is required
- whether n8n is required

## Architecture

Always follow HADES_ARCHITECTURE.md.

Never invent a different architecture.

---

## Goal

Build Hades step by step.

Every module must be production ready.

Quality is more important than speed.
